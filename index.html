Evidence Boundary

On-chain records establish transaction facts. IP/identity correlation is not inferred from a transaction hash and requires separate lawful, authorized off-chain intelligence.

Methodology

Research-grounded architecture and limitations.

Stage 8D architecture

Ethereum / Blockscout → FastAPI → normalization → graph → explainable risk → persistent case → evidence provenance → report.

Case persistence

SQLite stores investigation metadata, transactions, risk indicators and evidence references. Each transaction receives an evidence identifier and retrieval timestamp.

Risk source of truth

The backend is authoritative for risk scores and risk factors. The frontend only renders backend results; it no longer recalculates the investigation risk.

Limitations

Risk is an investigative prioritization signal, not proof of criminal conduct. A blockchain transaction does not inherently expose a user's IP address. Identity correlation requires separate lawful, authorized off-chain intelligence.

Evidence Boundary

On-chain records establish transaction facts. IP/identity correlation is not inferred from a transaction hash and requires separate lawful, authorized off-chain intelligence.

Methodology

Research-grounded architecture and limitations.

Research basis

ChainSight follows the graph/ML forensic direction of Pocher et al. (2023): cryptocurrency transactions are modeled as networks and analyzed for anomalous AML/CFT patterns.

Live pipeline

Ethereum API → transaction normalization → directed graph → explainable heuristics → risk score → investigator map/report.

Risk engine

The current live engine is intentionally explainable. It scores high transaction velocity, broad counterparty networks, interaction density, rapid activity and near-balanced in/out flow. This is investigative prioritization, not proof of criminal conduct.

ML roadmap

The next research stage can train Random Forest/XGBoost baselines and then GCN/GAT models on a labeled cryptocurrency transaction dataset.

IP limitation

A blockchain transaction does not inherently expose a user's IP address. Any IP or identity correlation must come from lawful, authorized off-chain sources with provenance and confidence metadata.
